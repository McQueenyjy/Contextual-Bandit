\begin{abstract}
Recommendation systems often need to compare new policies before exposing
users to them online. This project studies that problem as an offline
contextual bandit task for e-commerce recommendation. We implemented several
target policies, including uniform random recommendation, an epsilon-greedy
popularity policy, LinUCB, Logistic UCB, and Linear Thompson Sampling. We also
implemented four off-policy evaluation estimators: inverse propensity scoring,
self-normalized inverse propensity scoring, the direct method, and the doubly
robust estimator. Experiments on large-scale logged recommendation feedback
show that the epsilon-greedy popularity policy obtains the largest estimated
value among the core policies under IPS, SNIPS, and DR. However, learned
policies still have much smaller effective sample sizes than the random
baseline, so uncertainty diagnostics remain important for interpreting
offline policy comparisons.
\end{abstract}

\begin{IEEEkeywords}
contextual bandits, recommender systems, off-policy evaluation, inverse
propensity scoring, doubly robust estimation
\end{IEEEkeywords}

\section{Introduction}

E-commerce recommenders must choose items for users under uncertainty. A
contextual bandit formulation captures this setting naturally: at each round,
the system observes a user context, selects an item, and receives a reward
such as a click. The key evaluation challenge is that deploying every new
recommendation policy online is costly and risky. Historical logs are useful,
but they are biased toward the behavior policy that generated them. Therefore,
the central question of this project is:
\begin{quote}
Can we estimate the value of new recommendation policies using only logged
bandit feedback?
\end{quote}

We address this question by implementing an offline evaluation pipeline. The
pipeline splits logged feedback into training and evaluation portions, learns
target recommendation policies from the training split, estimates policy
values on the evaluation split, and reports uncertainty and stability
diagnostics. The goal is not only to identify policies with high point
estimates, but also to understand when those estimates are reliable.

Our main contributions are:
\begin{itemize}
    \item implementation of five contextual bandit recommendation policies;
    \item implementation of IPS, SNIPS, DM, and DR estimators;
    \item bootstrap confidence intervals for policy value estimates;
    \item effective-sample-size diagnostics for offline evaluation stability;
    \item a hyperparameter sweep over the main policy families.
\end{itemize}

\section{Background}

\subsection{Contextual Bandits}

In a contextual bandit problem, each logged round contains a context
$x_i \in \mathcal{X}$, an action $a_i \in \mathcal{A}$, a reward $r_i$, and
the behavior-policy probability $\pi_b(a_i|x_i)$. A target policy $\pi$ maps
a context to a distribution over actions. The value of a target policy is
\begin{equation}
V(\pi) =
\mathbb{E}_{x \sim \mathcal{D}, a \sim \pi(\cdot|x)}
\left[r(x,a)\right].
\label{eq:policy_value}
\end{equation}
The challenge is that logged feedback only reveals the reward for the action
actually selected by the behavior policy.

\subsection{Off-Policy Evaluation}

Off-policy evaluation (OPE) estimates $V(\pi)$ from data generated by a
different behavior policy. The basic correction is the importance weight
\begin{equation}
w_i = \frac{\pi(a_i|x_i)}{\pi_b(a_i|x_i)}.
\label{eq:importance_weight}
\end{equation}
If the target policy puts most of its probability on actions rarely selected
by the behavior policy, only a small fraction of the log effectively supports
the estimate. This support problem is especially important in large action
spaces and sparse click settings.

\section{Dataset}

We used the full-size Open Bandit Dataset collected from the ZOZOTOWN fashion
e-commerce platform \cite{saito2020open}. The dataset contains logged
recommendation impressions with user features, item actions, item context,
observed click rewards, and propensity scores from the logging policy. We
used the random behavior-policy logs from the all-item campaign. The data
were randomly split into equal-sized training and evaluation sets.

\section{Methods}

\subsection{Target Policies}

We evaluated five target policies.

\textbf{Uniform Random.} This baseline assigns equal probability to every
item:
\begin{equation}
\pi(a|x) = \frac{1}{|\mathcal{A}|}.
\end{equation}
It is useful as a sanity check because it is close to the random behavior
policy.

\textbf{Epsilon-Greedy Popularity.} This policy estimates the mean reward for
each action on the training split. It chooses the historically best action
$a^*$ with probability $1-\epsilon$ and explores uniformly with probability
$\epsilon$:
\begin{equation}
\pi(a|x) =
\begin{cases}
1-\epsilon+\frac{\epsilon}{|\mathcal{A}|}, & a = a^*,\\
\frac{\epsilon}{|\mathcal{A}|}, & a \neq a^*.
\end{cases}
\end{equation}

\textbf{LinUCB.} LinUCB fits a separate linear reward model for each action
and chooses the action with the largest optimistic score:
\begin{equation}
a_t =
\arg\max_a
\left(
x_t^\top \hat{\theta}_a
+ \alpha \sqrt{x_t^\top A_a^{-1}x_t}
\right).
\label{eq:linucb}
\end{equation}
The first term estimates reward, while the second term adds an uncertainty
bonus.

\textbf{Logistic UCB.} Logistic UCB uses combined user and item features to
model click probability. It then adds an uncertainty bonus and selects the
action with the largest optimistic click score.

\textbf{Linear Thompson Sampling.} Linear Thompson Sampling fits per-action
linear reward models and samples plausible parameters from a Gaussian
posterior approximation:
\begin{equation}
a_t = \arg\max_a x_t^\top \tilde{\theta}_a,
\quad
\tilde{\theta}_a \sim
\mathcal{N}(\hat{\theta}_a, \sigma^2 A_a^{-1}).
\end{equation}

\subsection{Reward Model}

The direct method and doubly robust estimator require an estimate of expected
reward for every context-action pair:
\begin{equation}
\hat{q}(x,a) \approx \mathbb{E}[r|x,a].
\end{equation}
We trained a logistic reward model on the training split using the logged
action for each round and a feature vector formed by concatenating user
context and item context. The model then predicts $\hat{q}(x_i,a)$ for every
candidate action in each evaluation round.

\subsection{OPE Estimators}

We implemented four OPE estimators.

\textbf{Inverse Propensity Scoring.} IPS estimates target-policy value by
reweighting observed rewards:
\begin{equation}
\hat{V}_{IPS}(\pi)
= \frac{1}{n}\sum_{i=1}^{n} w_i r_i.
\label{eq:ips}
\end{equation}

\textbf{Self-Normalized IPS.} SNIPS normalizes the importance weights:
\begin{equation}
\hat{V}_{SNIPS}(\pi)
= \frac{\sum_{i=1}^{n} w_i r_i}
{\sum_{i=1}^{n} w_i}.
\label{eq:snips}
\end{equation}

\textbf{Direct Method.} DM estimates value only through the reward model:
\begin{equation}
\hat{V}_{DM}(\pi)
= \frac{1}{n}\sum_{i=1}^{n}
\sum_{a \in \mathcal{A}} \pi(a|x_i)\hat{q}(x_i,a).
\label{eq:dm}
\end{equation}

\textbf{Doubly Robust.} DR combines the reward-model estimate with an IPS
correction term:
\begin{equation}
\hat{V}_{DR}(\pi)
= \frac{1}{n}\sum_{i=1}^{n}
\left[
\sum_{a \in \mathcal{A}}\pi(a|x_i)\hat{q}(x_i,a)
+ w_i(r_i-\hat{q}(x_i,a_i))
\right].
\label{eq:dr}
\end{equation}
DR is useful because it combines model-based prediction with logged reward
correction.

\subsection{Effective Sample Size}

We use effective sample size (ESS) to diagnose whether a target policy is well
supported by the logged data:
\begin{equation}
ESS =
\frac{\left(\sum_{i=1}^{n} w_i\right)^2}
{\sum_{i=1}^{n} w_i^2}.
\label{eq:ess}
\end{equation}
We report the ESS ratio $ESS/n$. A low ESS ratio means the estimate depends
on a small effective number of logged rounds, even when the raw evaluation set
is large.

\section{Experiments}

The training split was used to fit target policies and the reward model. The
evaluation split was used only for OPE. For the core experiment, we evaluated
one representative configuration from each policy family: uniform random,
epsilon-greedy popularity with $\epsilon=0.2$, LinUCB with $\alpha=0.5$,
Logistic UCB with $\alpha=0.5$, and Linear Thompson Sampling with sampling
scale 0.2.

For uncertainty, we used nonparametric bootstrap resampling over evaluation
rounds with 200 bootstrap samples. We also performed a policy sweep over
epsilon-greedy exploration rate, UCB exploration strength, and Thompson
Sampling posterior scale.

\section{Results}

\subsection{Core Policy Values}

Table~\ref{tab:core_values} reports the core policy estimates. The behavior
policy mean reward on the evaluation split is 0.003420. The epsilon-greedy
popularity policy obtains the largest core IPS, SNIPS, and DR estimates:
0.006272, 0.006199, and 0.006220, respectively. Logistic UCB also improves
over the behavior baseline under IPS, SNIPS, and DR, though its confidence
intervals are wider. LinUCB is close to the behavior baseline, while Linear
Thompson Sampling has a lower IPS estimate but a DM estimate above the
baseline.

model: model-based estimates can disagree with importance-weighted estimates,
so they should not be interpreted in isolation.

\subsection{Confidence Intervals}

Figure~\ref{fig:confidence_intervals} shows bootstrap confidence intervals.
The full dataset reduces uncertainty substantially compared with small-sample
experiments, but intervals are still nontrivial for learned policies. The
epsilon-greedy popularity policy remains clearly above the behavior baseline
under IPS, SNIPS, and DR. Logistic UCB has a positive point estimate, but its
interval overlaps the baseline more closely. Linear Thompson Sampling has
wide intervals and does not show a robust improvement under IPS or DR.

\subsection{Effective Sample Size}

Although the evaluation split contains 687,163 rounds, the effective sample
sizes for learned policies are much smaller. Table~\ref{tab:ess} shows that
uniform random has ESS ratio 1.0, while the learned policies have ESS ratios
near 1--2 percent. This means that the full dataset improves statistical
power, but aggressive target policies are still evaluated using a much smaller
effective amount of information.

These diagnostics explain why confidence intervals remain important even with
more than one million logged rounds. Offline evaluation depends not only on
the raw number of observations, but also on how much probability the target
policy assigns to actions that are well represented in the log.

\subsection{Policy Sweep}

The policy sweep highlights how hyperparameters affect estimated value. For
epsilon-greedy popularity, lower $\epsilon$ values concentrate more probability
on the historically best action and produce higher DR estimates. As
$\epsilon$ approaches 1, the policy becomes uniform random and its value
approaches the behavior baseline. Logistic UCB performs best in the sweep at
$\alpha=0$, while larger uncertainty bonuses reduce the DR estimate. LinUCB
changes little for $\alpha \leq 0.5$ and drops for larger $\alpha$. Linear
Thompson Sampling performs best at a small sample scale and degrades as the
sampling scale grows.

\section{Discussion}

The strongest empirical result is that a simple popularity-based policy is
competitive in this offline setting. Both the core experiment and the sweep
show that epsilon-greedy popularity obtains the highest estimated values under
importance-weighted and doubly robust estimators. This suggests that the
logged reward signal contains strong action-level popularity effects.

The learned contextual policies give more mixed results. Logistic UCB improves
over the baseline under IPS, SNIPS, and DR, but its direct-method estimate is
below the behavior baseline. LinUCB is close to the baseline, and Linear
Thompson Sampling is sensitive to the estimator. These results suggest that
contextual generalization is more difficult than exploiting global popularity
in this setting, at least with the linear and logistic models implemented
here.

The ESS diagnostics also show that policy value alone is incomplete. Even on
the full dataset, deterministic or nearly deterministic target policies have
ESS ratios around one or two percent. Therefore, a responsible offline
evaluation should report both point estimates and uncertainty. The full data
provide substantial evidence, but they do not remove the fundamental support
issue in large-action contextual bandits.

\section{Limitations}

This study has several limitations. First, the reward is a sparse click
indicator, so even a large log has limited positive feedback relative to the
80-action space. Second, the reward model is trained only from logged actions,
which can make DM estimates sensitive to extrapolation. Third, the target
policies are relatively simple; stronger nonlinear contextual models may
perform differently. Finally, offline OPE estimates are useful for screening
policies, but they do not replace controlled online experiments.

\section{Conclusion}

We implemented an offline contextual bandit evaluation pipeline for
e-commerce recommendation. The pipeline includes multiple target policies,
four OPE estimators, reward modeling, bootstrap confidence intervals, ESS
diagnostics, and policy hyperparameter sweeps. On the full logged dataset,
the behavior-policy mean reward in the evaluation split is 0.003420. Uniform
random closely matches this baseline, with DR estimated value 0.003419.
Among the core policies, epsilon-greedy popularity performs best under the
three estimators that use logged rewards directly, with IPS 0.006272, SNIPS
0.006199, and DR 0.006220. Logistic UCB is the strongest contextual policy in
the core comparison, with DR 0.004385, while LinUCB is close to the behavior
baseline with DR 0.003754. Linear Thompson Sampling is weaker under IPS and
DR in the core setting, with DR 0.003080, although its direct-method estimate
is above the behavior baseline.

The sweep gives a similar picture. A fully greedy popularity policy
($\epsilon=0$) reaches the largest DR estimate, 0.006920, followed by
Logistic UCB with $\alpha=0$, whose DR estimate is 0.005922. LinUCB's best
sweep result is much closer to the baseline, with DR 0.003756, and Linear
Thompson Sampling remains below the baseline in its best sweep configuration,
with DR 0.003316. Overall, the empirical evidence suggests that simple
popularity information is highly predictive in this dataset, while the
implemented linear contextual policies provide smaller and less consistent
gains.

At the same time, the learned policies have low ESS ratios, around 1--2
percent, compared with 1.0 for uniform random. Therefore, the main conclusion
is that OPE is useful for comparing recommendation policies before deployment,
but policy values should be interpreted together with estimator agreement,
confidence intervals, and effective sample size.
